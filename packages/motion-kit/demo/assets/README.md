# Demo images

These images are stored locally so the demo works without requests to external
image hosts. Their licenses are separate from the source code license.

## Cornell box

`cornell-box.png` is the 960-pixel Wikimedia thumbnail of
[Cornell Box multispectral imaging.png](https://commons.wikimedia.org/wiki/File:Cornell_Box_multispectral_imaging.png).
Michal Czerniawski (Czerniawskimc) assembled the image from data provided by
Cornell University. The image is released under
[CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/). The thumbnail is
resized by Wikimedia; it is otherwise unchanged here.

## Stanford bunny

`stanford-bunny.png` is
[Mesh bunny.png](https://commons.wikimedia.org/wiki/File:Mesh_bunny.png) by
G1malitm, a mesh rendering of the Stanford bunny. It is used unchanged under
[CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/). The image
retains that license. The demo scales and crops it to fill the card's image
frame.
